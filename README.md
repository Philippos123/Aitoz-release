# Aitoz Desktop (Tauri)

Skrivbordsklient för Aitoz. Se instruktioner i chatten för nästa steg:
1. npm install -D @tauri-apps/cli@2
2. npx tauri icon din-logga.png   (för att generera ikoner i src-tauri/icons/)
3. npx tauri dev                 (testa lokalt)
4. npx tauri build                (paketera .dmg / .msi)
